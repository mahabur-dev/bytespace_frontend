# ByteSpace

ByteSpace is a production-quality landing page implemented from its Figma design.

## Tech stack

- Next.js (App Router)
- TypeScript (strict mode)
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Folder structure

- `src/app/` — routing, metadata, and page composition
- `src/components/` — reusable UI, layout, and landing-page sections
- `src/data/` — typed static content
- `src/lib/` — utilities and validation schemas
- `public/` — images and icons
